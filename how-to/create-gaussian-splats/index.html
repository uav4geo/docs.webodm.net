Create Gaussian Splats

Gaussian splatting is a technique for creating photorealistic 3D scenes by using millions of semi-transparent, 3D ellipses (gaussians).

Gaussian splats are generated by "training" from the images + camera poses + sparse points of a photogrammetry scene exported from WebODM Lightning.

The "training" of gaussian splats can be done via several software packages. Once trained, the splats model can be displayed in WebODM Lightning alongside point clouds and textured models.

note

Gaussian splatting requires oblique and/or orbit shots in order to generate good results. You must capture the details of a scene from multiple viewpoints. A nadir-only flight, usually yields very poor results.

GPU required

Gaussian splatting requires processing on your own machine and requires a graphics card for good performance. Currently no cloud processing option is available.

Steps​

  1. Process a RGB dataset on WebODM Lightning
  2. Click ... next to a task and select Splats
  3. Download the training data file (.zip)
  4. Train the splats using one of the software listed below.
  5. Upload the resulting splat model to WebODM.

Software​

One of the following software are available for processing splats. OpenSplat is developed in-house, but only Windows binaries are available and require an NVIDIA card. For other platforms and cards, check out Brush or Spirula Studio.

SoftwareHardware SupportPlatformsNotes
OpenSplatCPU, NVIDIAWindowsSee workflow
BrushWebGPU, NVIDIA, AMD, IntelWeb, Windows, macOS, LinuxAlso works in the browser (Chrome)
Spirula StudioNVIDIA, AMD, Intel, and Apple (Vulkan)Windows, macOS, Linux
Lichtfeld StudioNVIDIAWindowsPaid binaries

OpenSplat Workflow​

Once you've downloaded the training.zip file from WebODM Lightning, drag & drop the training.zip file directly onto opensplat.exe. This will start the training process.

Once completed, a splat.ply will be placed in the same folder as the training.zip file. Upload this file to the Gaussian Splats dialog in WebODM Lightning.
