Add Design Overlays

From the cloud interface, after a task has been processed, you can overlay vector files on top of your maps. This is useful to compare a site plan, CAD drawings or any other vector design.

Adding an Overlay​

From the Map view, either drag and drop a file anywhere on the map, or use the Add a GeoJSON (.json), ShapeFile (.zip) or AutoCAD (.dxf) overlaybutton located in the top right corner of the map.

The following formats are supported:

FormatExtensionNotes
GeoJSON.jsonCoordinates must be in WGS84 (EPSG:4326)
Shapefile.zipCompress the .shp, .dbf, .shx and .prj files together in a ZIP file
AutoCAD.dxfYou will be asked for the 2D EPSG code of the drawing
note

DXF files do not store information about their coordinate system. When importing a DXF, the EPSG field is pre-populated with the coordinate system of the task, which is usually the correct choice if the drawing was prepared for the same site. If the drawing was created in a different coordinate system, enter its EPSG code instead.

Layers Within an Overlay​

DXF files and other vector features containing a Layer attribute are automatically split into sublayers. Each sublayer can be individually shown, hidden, colored and zoomed to.

Notes​

  • Overlays count towards the storage used by a task.
  • If you don't have permission to modify a task (for example when viewing a public map that isn't yours), you can still drag and drop a file to display it, but the overlay will disappear once you leave the page.
  • Files can be up to 100 MB in size.
